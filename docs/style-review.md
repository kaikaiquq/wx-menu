# 双主题视觉改造与样式审查

## 设计结果

本次检查并调整了全部 12 个页面，包括 5 个 Tab、聊天好友和群聊页、心愿单、登录页及 3 个管理页面。视觉方向是清晰的文字层级、克制的色彩、充足留白和细分隔线。

| 维度 | 女生主题 | 男生主题 |
| --- | --- | --- |
| 页面背景 | 暖白 `#F6F3EF` | 冷雾灰 `#F0F3F5` |
| 主色 | 莓棕 `#855461` | 深海墨 `#344B5E` |
| 内容底色 | 暖白卡片 | 白色卡片 |
| 标题字形 | 系统宋体 / 衬线回退 | 系统无衬线 |
| 卡片圆角 | 28rpx | 16rpx |
| 控件圆角 | 18rpx | 10rpx |
| 导航 | 统一线性图标，莓棕选中态 | 统一线性图标，深海墨选中态 |

尚未选择性别时使用完整的中性主题，避免先显示女生颜色再切换。两套主题共享信息层级和交互布局，差异落实到色彩、字体、轮廓及原生界面颜色。系统字体依赖设备可用字体，不额外下载字体文件。

## 原样式存在的问题与处理

| 原问题 | 影响 | 处理 |
| --- | --- | --- |
| 各页散落粉色、浅灰及不同状态色 | 男生主题仍出现粉色；维护容易遗漏 | 统一主题变量；系统弹窗、导航栏、地图标记也跟随主题 |
| 多处 14–21rpx 字号，浅色正文 | 小屏阅读吃力 | 主要正文约 26–30rpx，辅助文字至少 22rpx；加深辅助文本 |
| 主卡渐变、圆环、重阴影与多种圆角混用 | 焦点分散，页面之间不一致 | 纯色留言主卡、低对比边框、按主题统一圆角，减少装饰 |
| 点单侧栏和固定高度商品卡占用过多空间 | 长名称、说明、条件与加号拥挤 | 横向分类导航，全宽且随内容增长的商品卡 |
| 聊天好友区挤压主会话，输入工具争抢一行 | 输入框过窄，消息和时间可能互相挤压 | 好友覆盖抽屉、输入与工具分行、时间恢复正常文档流 |
| Tab、page 和页面容器重复预留底部空间 | 留白过大，固定底栏布局不一致 | 统一 108rpx Tab 高度，页面根容器负责一次安全区预留 |
| 部分弹层在遮罩内仍避让 Tab，层级不统一 | 面板悬空、底部暗色空洞、控件被遮 | 底部弹层贴底，内部预留安全区，层级高于 Tab |
| 长表单或历史内容没有可靠滚动 | 小屏操作和保存困难 | 分类编辑、菜单编辑、资料编辑、历史面板支持滚动 |
| 性别切换时原生颜色与已挂载 Tab 更新时机不同 | 顶栏与底栏短暂不一致 | `syncTheme` 同步导航、窗口和当前 Tab；Tab show 重新读取主题 |
| Emoji、字符图标和不同风格按钮混用 | 导航风格不统一 | 5 个 Tab 使用同一套 CSS 线性图标，保留消息角标 |

并未发现“所有页面都存在大量重复选择器”。部分重复来自基础规则和变体或媒体查询，是合理的；本次重点解决分散的设计值、无用装饰、布局约束和实际冲突。

## 样式组织

- `styles/tokens.wxss`：唯一的完整视觉变量表，使用类选择器，能被隔离的自定义 Tab 组件安全引入。
- `app.wxss`：全局字体、盒模型和字母头像基础样式，不承担具体页面布局。
- 各页面 `*.wxss`：布局和组件形态，使用主题变量，避免每页另写男女色值。
- `pages/admin/shared.wxss`：分类与菜单管理共用的表单、模板列表和底部编辑面板。
- `utils/theme.js`：原生导航背景、系统弹窗主色和运行时主题切换。这里少量颜色与 WXSS 保持一致，因为原生 API 不能读取 CSS 变量。
- `assets/location/*-{female,male,neutral}.png`：与地图原生标记配合使用的本地几何图标。气泡颜色从运行时主题读取。

后续新增页面应给根节点绑定 `themeClass`，静态 UI 颜色、圆角和标题字体优先使用现有变量。不要在单页尾部持续叠加硬编码主题覆盖。

## 关键版式

- 首页：日期和主标题、共同留言、分类入口、内容推荐，依顺序建立层级。
- 点单：分类横向选择，下方独立滚动商品列表，名称和条件支持换行。
- 位置：地图为主视觉，跟随模式分段选择，双方更新时间以信息行呈现，共享权限说明排在后方。
- 消息：保留现有消息能力，改善会话名称、气泡、图片宽度、时间和输入工具的空间分配。
- 我们：关系与纪念日作为视觉焦点，历史心愿和管理入口以列表分组。
- 管理及授权：标题、字段标签、输入内容和主操作分层；危险操作独立使用语义色。

## 已完成验证

1. 逐页核对 WXML 与样式，保留业务事件和输入绑定。
2. 检查共享变量引用、样式导入、WXML 标签闭合及差异空白错误。
3. 对三套主题的辅助文本与常用背景进行对比度计算：在背景、卡片、灰底和浅主色底上的最低值，中性约 4.90:1、女生约 4.66:1、男生约 4.75:1。这里只代表所核对的静态文本色对，不代表全部动态图像均已完成无障碍验收。
4. `npm test`：91 项现有业务及主题切换测试通过。
5. 浏览器使用真实 WXML/WXSS 生成的预览，对首页、点单、位置、消息、我们和心愿单进行视觉抽查，包含 320、390、430px 的代表场景。

本次未进行微信真机测试。原生地图、微信字体回退、软键盘上推、录音浮层、`scroll-view` 与刘海屏安全区需要在开发者工具和真机复核。浏览器预览不替代这些平台行为。

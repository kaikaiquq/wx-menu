<h1 align="center">两人菜单</h1>

<p align="center">情侣共同空间微信小程序：一起维护菜单、发送心愿、回应并记录约定。</p>

## 项目简介

两人菜单面向情侣场景，支持视频、甜点、饮料、正餐、小食和约会惊喜等自定义内容。点单条件不局限于金额，也可以是“一个抱抱”“你来选电影”等约定。

技术栈为微信原生小程序 + 微信云开发。用户资料、个人内容库、共同空间、心愿单和点单记录均保存在云端。

## 主要功能

- 微信登录，自主选择头像、昵称和性别
- 女性粉色 / 男性灰蓝双主题
- 独立个人内容库
- 邀请码绑定情侣（复制或分享卡片）
- 绑定后创建空白共同空间
- 从个人库导入，或「新建并加入」共同空间
- 共享留言簿
- 心愿单、点单、回应与完成闭环
- 分类 / 菜单管理与图片上传
- 解绑清空共同空间，个人内容不受影响

## 数据模型

### 个人内容库

- 每个用户独立的 `userConfigs`
- 绑定 / 解绑不会改写个人内容

### 情侣共同空间

- 每次绑定创建新的 `coupleId`
- 初始菜单、心愿、留言、订单为空
- 解绑后共同数据清空且不可恢复

## 技术栈

- 微信原生小程序（JavaScript / WXML / WXSS）
- 微信云开发（云函数、云数据库、云存储）

## 开始使用

1. 安装微信开发者工具，注册小程序并开通云开发。
2. 在开发者工具中把 AppID 换成自己的。
3. 将云环境 ID 写入 `config/cloud.js`：

```javascript
module.exports = {
  envId: '你的云环境 ID',
};
```

4. 按 [云开发开通与部署](./docs/cloud-setup.md) 创建数据库集合并部署三个云函数。
5. 编译预览即可，**无需构建 npm**。

## 核心流程

1. 各自维护「我的内容库」
2. 一方生成邀请码，另一方加入并填写纪念日
3. 向共同空间导入或新建内容
4. 点单 → 回应 → 完成心愿
5. 需要时可解绑；共同空间清空，个人库保留
